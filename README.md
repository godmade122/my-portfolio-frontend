# Graphic Designer Portfolio Website

A modern, fully responsive portfolio website for a graphic designer built with HTML, CSS, and JavaScript.

## Features

- Clean, minimal design with smooth animations
- Fully responsive (desktop, tablet, mobile)
- Sticky navigation with hamburger menu for mobile
- Dark/Light mode toggle
- Smooth scrolling
- Hover effects and transitions
- Contact form
- Social media links

## Sections

- Header/Navigation
- Hero Section
- About Section
- Portfolio Gallery
- Services
- Testimonials
- Contact
- Footer

## Setup

1. Clone or download the files
2. Open `index.html` in your browser

## Adding Images

Place your images in the `asset/` folder with the following names:

- `profile.jpg` - Your profile picture (square, 300x300px recommended)
- `project1.jpg` to `project6.jpg` - Portfolio project images (any size, will be cropped to fit)

## Customization

- Edit `styles.css` to change colors, fonts, and layout
- Update content in `index.html`
- Modify animations and interactions in `script.js`

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (ES6+)
- Font Awesome for icons

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
